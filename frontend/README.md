# SWD392 - Tư Vấn Luật Giao Thông Việt Nam

## Chạy nextjs local
`npm install`
Create .env file, copy value from sheet
`npm run dev`

## Chạy project cho nextjs trong devcontainer (when changed, rec-compile)
`CHOKIDAR_USEPOLLING=true npm run dev`
